Variable Acceleration Quiz

Test your knowledge of calculus-based kinematics where acceleration is a function of time, velocity, or position.

1. The acceleration of a particle is given by a(t) = 6t - 4 m/s². If the particle starts from rest at the origin, what is its velocity at t = 3 seconds?

2. A body moves along a straight line such that its velocity is v(t) = 3t² + 2t. What is the total displacement of the body between t = 1s and t = 2s?

3. The position of an object is defined by s(t) = t³ - 6t² + 9t. At what time t > 0 is the acceleration of the object equal to zero?

4. If acceleration is given as a function of velocity, a = -0.5v, and the initial velocity is v₀ = 10 m/s, which expression correctly describes the velocity at time t?

5. An object’s acceleration is a(v) = 2√v. If the object starts with velocity v = 4 m/s at t = 0, find the time taken for the velocity to reach 9 m/s.

6. For a particle where acceleration is a function of position, a(x) = 4x, which relationship should be used to find the velocity as a function of position?

7. The velocity of a particle is v = kx where k is a constant and x is position. What is the acceleration of the particle in terms of x?

8. A rocket's acceleration increases linearly with time: a(t) = kt. If it starts from rest, the displacement s is proportional to which power of t?

9. A particle moves such that v = 2t². What is the average acceleration between t = 0 and t = 3 seconds?

10. If the jerk (rate of change of acceleration) is a constant j = 2 m/s³ and the object starts from rest with zero initial acceleration, what is its velocity at t = 2s?

Answer Key & Complete Solutions

Question 1: B) 15 m/s

Integrate acceleration to find velocity: v(t) = ∫(6t - 4)dt = 3t² - 4t + C. Since it starts from rest, C = 0.
At t = 3s: v(3) = 3(3)² - 4(3) = 27 - 12 = 15 m/s.

Question 2: C) 10 m

Displacement is the definite integral of velocity: Δs = ∫[1 to 2] (3t² + 2t) dt.
Antiderivative is [t³ + t²] evaluated from 1 to 2.
At t = 2: (2³ + 2²) = 8 + 4 = 12.
At t = 1: (1³ + 1²) = 1 + 1 = 2.
Δs = 12 - 2 = 10 m.

Question 3: B) t = 2 s

Velocity is the first derivative: v(t) = s'(t) = 3t² - 12t + 9.
Acceleration is the second derivative: a(t) = v'(t) = 6t - 12.
Set a(t) = 0: 6t - 12 = 0 → 6t = 12 → t = 2 s.

Question 4: B) v(t) = 10e^(-0.5t)

Write acceleration as dv/dt: dv/dt = -0.5v.
Separate variables: (1/v) dv = -0.5 dt.
Integrate both sides: ln(v) = -0.5t + C → v(t) = e^(-0.5t + C) = A*e^(-0.5t).
Using initial condition v(0) = 10 gives A = 10, so v(t) = 10e^(-0.5t).

Question 5: B) 1.0 s

dv/dt = 2√v → v^(-1/2) dv = 2 dt.
Integrate both sides: 2√v = 2t + C → √v = t + C.
At t = 0, v = 4 → √4 = 0 + C → C = 2. Therefore, √v = t + 2.
Find t when v = 9: √9 = t + 2 → 3 = t + 2 → t = 1.0 s.

Question 6: B) v dv = a dx

Using the chain rule, acceleration can be rewritten from dv/dt into a position-dependent form:
a = (dv/dx) * (dx/dt). Since dx/dt = v, this simplifies to a = v(dv/dx), which rearranges cleanly to v dv = a dx.

Question 7: C) a = k²x

Using a = v(dv/dx):
Given v = kx, differentiate with respect to x: dv/dx = k.
Substitute back into formula: a = (kx) * (k) = k²x.

Question 8: C) t³

First integration for velocity: v(t) = ∫ kt dt = (1/2)kt² + C₁.
Second integration for displacement: s(t) = ∫ (1/2)kt² dt = (1/6)kt³ + C₁t + C₂.
Thus, displacement is directly proportional to t³.

Question 9: A) 6 m/s²

Average acceleration is defined as change in velocity divided by change in time: a_avg = (v_final - v_initial) / Δt.
v(3) = 2(3)² = 18 m/s.
v(0) = 2(0)² = 0 m/s.
a_avg = (18 - 0) / (3 - 0) = 6 m/s².

Question 10: B) 4 m/s

Jerk is the derivative of acceleration (j = da/dt), so a(t) = ∫ j dt = ∫ 2 dt = 2t.
Velocity is the integral of acceleration: v(t) = ∫ 2t dt = t².
At t = 2s: v(2) = 2² = 4 m/s.
